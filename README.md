# ✂️ HairConcept [Beta] — Gestão para Salões & Barbearias

O **HairConcept** é uma aplicação web moderna e intuitiva para gestão de agendamentos e cadastros de clientes em salões de beleza, barbearias e clínicas de estética. 

O projeto combina uma **interface em Dark Mode de alto impacto visual** com **recursos dinâmicos de agendamento em tempo real**, focando em acessibilidade e excelente experiência do usuário (UX/UI).

---

## 🚀 Funcionalidades

* **🗓️ Agenda Interativa em Tempo Real:** Visualização completa da grade diária por profissional, com destaque visual de status e navegação suave (*scrollIntoView*) até o horário selecionado.
* **⚡ Seleção Inteligente por Chips:** Escolha de horários via botões (*chips/pills*) que indicam automaticamente se o slot está disponível ou ocupado.
* **🛡️ Controle de Visibilidade por Perfil:** Alternância instantânea entre o **Modo Salão / Gestor** (visão geral da equipe) e o **Modo Profissional** (foco na agenda individual).
* **👤 Cadastro Rápido de Clientes:** Formulário otimizado para a rotina do salão, com suporte a upload de foto de perfil (preview Base64) e campos expansíveis para dados fiscais (CPF/RG).
* **🎨 Design Responsivo & Temático:** Layout adaptável para dispositivos móveis e desktops utilizando **Tailwind CSS**.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica e acessível.
* **Tailwind CSS:** Estilização utilitária e responsiva em Dark Mode.
* **JavaScript (Vanilla ES6+):** Manipulação dinâmica do DOM, controle de estado dos chips e navegação por abas sem dependência de frameworks pesados.
* **FontAwesome:** Iconografia visual moderna.
* **Google Fonts (Inter):** Tipografia limpa e legível.

Este projeto foi desenvolvido e refinado com o **suporte do Gemini**, atuando como parceiro técnico e consultor de UX/UI para:
